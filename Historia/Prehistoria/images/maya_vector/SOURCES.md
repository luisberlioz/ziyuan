# Numerales mayas — esquemas vectoriales

Veinte dibujos didácticos originales (0–19), creados para esta presentación el
2026-09-17. No son fotografías, calcos arqueológicos ni glifos de una fuente.
Se ofrecen bajo CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/

Convención: puntos (unidades) encima de barras horizontales (cincos); cero como
concha estilizada. Las variantes históricas de cero no se reducen a esta forma.
Cada archivo conserva el mismo lienzo y tamaño de punto/barra.

Correspondencia Unicode: U+1D2E0–U+1D2F3 = valores 0–19; el bloque completo
es U+1D2E0–U+1D2FF y tiene posiciones sin asignar. Referencia del repertorio:
https://www.unicode.org/charts/PDF/U1D2E0.pdf

Generación reproducible, sin red ni fuentes: `python3 scripts/generate_maya.py`
(requiere `rsvg-convert`). PDFLaTeX incluye los PDF vectoriales locales; no
necesita convertir SVG ni instalar una fuente maya en cada compilación.
